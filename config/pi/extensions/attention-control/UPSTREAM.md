# Attention Control source

`style.md` copies the body of `output-styles/attention-control.md` from [mzizzi/attention-control](https://github.com/mzizzi/attention-control), commit `3c8a2a8a38f163aa85ad325812b5ce3ba330ad27`. This repo maintains the copy independently for Pi. Setup and runtime need no external checkout or download.

Local changes remove the broad task-tool mandate and add a separate policy for explicit task-tracking requests or long-horizon work. These changes apply only to Pi, not to the external style or other agents.
