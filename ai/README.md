# AI resource sources

Keep shared skills under `<namespace>/skills/<local-name>/SKILL.md.j2` with their supporting resources. Keep shared agents under `<namespace>/agents/<local-name>.md.j2`.

These are staging sources for the mzizzi plugin port. Production copies under `plugins/mzizzi/` remain active until deployment. Sandbox startup registers the generated Pi package for pilot use. Renderer fixtures live under `ai-renderer/tests/fixtures/source/`, not here.

See [the renderer documentation](../ai-renderer/README.md) for authoring, generation, and loader checks.
