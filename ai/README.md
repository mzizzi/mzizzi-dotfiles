# AI resource sources

Keep shared skills under `<namespace>/skills/<local-name>/SKILL.md.j2` with their supporting resources.

`development-preferences` and `create-plan-dir` are staging sources for the pilot migration. Their production copies under `plugins/mzizzi/skills/` remain active until deployment. Do not treat these staging copies as deployed skills or remove the production copies yet. `renderer-example` tests generated references between skills and is not a production skill.

See [the renderer documentation](../ai-renderer/README.md) for authoring, generation, and loader checks.
